# موقع Market Code Agency

موقع ثابت (HTML/CSS/JS) جاهز للنشر على GitHub Pages، من غير أي تثبيت أو build.

## الملفات
| الملف | بيعمل إيه |
|---|---|
| `content.js` | **كل النصوص (عربي وإنجليزي) + التليفون والإيميل والروابط والألوان + أسماء الصور** |
| `assets/` | الصور: `logo.png` / `clients/` / `video/` / `photo/` / `graphic/` |
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم |
| `app.js` | الكود (مش محتاج تلمسه) |

## النشر على GitHub Pages
1. ادخل github.com ← **New repository** ← سمّيه مثلاً `marketcode-site` ← **Public** ← Create.
2. اضغط **uploading an existing file** وارفع **كل محتويات** الفولدر (مش الفولدر نفسه، ولازم `assets` يترفع بمحتواه) ← Commit changes.
3. من **Settings ← Pages**: Source = *Deploy from a branch* ← Branch = `main` و `/ (root)` ← Save.
4. بعد دقيقة أو اثنين الموقع يظهر على: `https://USERNAME.github.io/marketcode-site/`

## التعديل
- افتح `content.js` على GitHub ← أيقونة القلم ✏️ ← عدّل ← **Commit changes**. الموقع يتحدث لوحده خلال دقيقة.
- **نص/تليفون/إيميل/لينك:** غيّر القيمة بين علامات التنصيص. لينكات `behance` و`facebook` و`instagram` فاضية، حط الرابط وهيظهر.
- **لون:** في `theme` غيّر الأكواد (مثلاً `ac: "#c026a3"`).
- **إضافة خدمة:** انسخ سطر خدمة كامل `["العنوان","الوصف"],` في `ar` وكمان في `en`، ولازم نفس الترتيب في اللغتين.
- **إضافة صورة شغل:** ارفع الصورة في `assets/video` أو `photo` أو `graphic` (يفضل مربعة تقريباً 900px)، وبعدين ضيف اسمها في القايمة بنفس القسم في آخر `content.js`.
- **حذف صورة:** شيل سطرها من `content.js`.
- **تغيير اللوجو:** ارفع صورة بنفس الاسم `assets/logo.png` (PNG أبيض بخلفية شفافة).

## ملاحظات
- لو بتجرب على جهازك، افتح `index.html` مباشرة في المتصفح.
- لو غلطت في `content.js` (فاصلة أو علامة ناقصة) الموقع ممكن يبان فاضي، راجع آخر تعديل أو ارجع للنسخة السابقة من Commits.
- الصور الحالية مقصوصة من ملف الـPDF، فاستبدلها بالأصلية لما تقدر.
